# 📁 مجلد الأصول (assets/)

هذا المجلد يُنشأ تلقائياً ويحتوي على:

| المجلد | الوصف |
|---|---|
| `raw/` | الصور الخام المرفوعة من المستخدم قبل المعالجة |
| `output/` | الصور الإعلانية المولّدة النهائية |
| `temp/` | ملفات مؤقتة أثناء المعالجة |

> ملاحظة: عند استخدام Supabase، تُرفع الصور للسحابة ولا تبقى هنا.
> هذه المجلدات تُستخدم فقط في وضع LocalStorage fallback.

## ملفات .gitkeep

المجلدات الفارغة قد لا تُحتسب في Git، لذا أضِف ملف `.gitkeep` لكل منها
إن أردت تتبّعها.
